# ToDo App (Nuxt 3)

Это простое ToDo-приложение, написанное на Nuxt 3 с использованием Pinia, VueUse и Tailwind.

## Возможности:
- Добавление задач
- Удаление задач
- Редактирование задач
- Хранение данных в памяти
- Работа с VueUse и Pinia
- Подключённый Git и деплой на GitHub Pages

## Запуск проекта
```bash

npm install
npm run dev

```
